# Contributing

Start with the [getting-started guide](docs/guides/getting-started.md) to install
and try the current foundation. Find or propose an issue using the issue chooser;
agree substantial scope with the maintainer before implementation.

Follow the [working agreement](docs/working-agreement.md) for task selection,
branches, local review, publication authorization, and maintainer approval and merge.
Update affected documentation under [documentation guidance](docs/AGENTS.md).

Run the relevant [checks](docs/guides/testing.md) and describe the resulting
behavior and validation in the short PR template. Identify final scope and include
a separate `Closes #N` for each issue fully delivered. Disclose unavailable checks.
