# Bundle verification

`import.ts` invokes the Lambda bundle generated by `infra/cdk/synth.ts` and checks
that development tools stay out of runtime inputs. CI runs this integration test
through `pnpm run toolchain:import` after `pnpm run toolchain:bundle`; it is separate
from the source unit tests run by `pnpm test`. The example source and tests
live in `apps/api`, with its shared schema in `packages/contracts`.

See [testing guidance](../../docs/guides/testing.md) for commands.
